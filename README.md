# HappyTails – A Pet Adoption Portal

A full-stack web application designed to connect animal shelters and adopters, allowing users to browse, filter, and adopt pets, while shelters can manage listings and applications efficiently. Built using **Next.js** with MongoDB as the database.

---

## 📧 Project Overview

**Project Type:** Full-stack web application  
**Sector of Use:** Animal Welfare and Adoption  
**Technology:** Next.js (Frontend & API routes), MongoDB (Database)

HappyTails aims to make pet adoption seamless for both adopters and shelters. It provides a modern, responsive interface with advanced filtering, dashboards, and secure payment integration.

---

## 🌟 Core Features

1. **Pet Listings with Filters**  
   Browse pets with filters for species, breed, age, gender, size, and location.

2. **Pet Detail Page**  
   View pet profiles with vaccination status, health info, adoption fee, and shelter contact.

3. **Adoption Application Form**  
   Submit adoption applications with personal details, experience, and reasons for adoption.

4. **User Dashboard**  
   Track submitted applications and their status (pending, approved, rejected).

5. **Shelter Dashboard**  
   Manage pet listings and adoption applications efficiently.

6. **Pet Status Management**  
   Shelters can mark pets as available, reserved, or adopted.

7. **Favorites/Wishlist**  
   Save favorite pets for quick access later.

8. **Announcements Section**  
   Admins can post system-wide announcements or adoption events.

9. **Pet Care Tips**  
   Blog/articles about pet care, health, and training.

10. **Search & Location-Based Filtering**  
    Search pets and filter based on preferred locations.

## 🏗️ Technology Stack

- **Frontend & Backend:** Next.js (SSR & SSG, API Routes)
- **Database:** MongoDB
- **Authentication:** Firebase Auth
- **Payment Gateway:** Stripe (for adoption fees and donations)
- **State Management & Data Fetching:** React Query
- **Styling:** Tailwind CSS + DaisyUI
- **Image Handling:** Next.js Image Optimization

**Why Next.js?**

- Server-Side Rendering (SSR) & Static Site Generation (SSG) for faster page loads and better SEO.
- Built-in API routes simplify backend integration.
- Dynamic routing enables detailed pet and shelter pages.
- Optimized image loading for better user experience.
- Modern framework used widely in industry, ensuring professional-grade application.
